## 📁 目录结构

```
GFSF/
├── algorithms/        # 算法实现（排序、查找、动态规划等）
├── data-structures/   # 数据结构（链表、栈、队列、树、图等）
├── leetcode/          # 刷题记录（按题号整理）
├── templates/         # 常用算法模板
├── README.md          # 项目说明
└── VERSION            # 版本信息
```

> 具体内容随版本迭代逐步补充。

---

## 🚀 快速开始

1. 克隆仓库

```bash
git clone https://github.com/ssmhdssmhd/GFSF.git
```

2. 选择对应的算法目录进入即可查看或运行示例代码。
